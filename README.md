# Erasight_Course_Web

Trang web giới thiệu và tuyển sinh các chương trình đào tạo thực chiến của **Erasight Academy**:
- **01. AI Marketing thực chiến** (`MKT_001`): Tự động hoá quy trình đăng bài đa kênh không cần code.
- **02. Tiếng Anh phỏng vấn & đi làm** (`ENG_002`): CV chuẩn ATS và phản xạ phỏng vấn STAR cùng cố vấn công ty lớn.

## Cấu trúc dự án
- `index.html`: Landing page chính thức chuẩn nhận diện thương hiệu Erasight Course v2.0
- `demo-page.html`: Trang mẫu minh họa việc tái sử dụng Header & Footer
- `assets/css/header-footer.css`: Bộ CSS độc lập cho Header, Footer, Dropdown & Mobile Drawer
- `assets/js/components.js`: Script nạp và điều khiển Header & Footer tự động trên mọi trang
- `components/`: Chứa file mã nguồn HTML mẫu và tài liệu hướng dẫn tái sử dụng
